# 플듀 미스터리 EP.01 「자정에 멈춘 시계」 — 시나리오 설계서 (정답 포함, 비공개)

> 사건 데이터 원본은 `src/mystery-ep01.js`. 이 문서와 어긋나면 데이터 파일이 우선.

## 1. 무대

- **에셀 마을**: 언덕 위 작은 유럽풍 마을. 1847년 3월 15일 창건(광장 창건 동판).
- **동기 시계 체계**: 광장 시계탑 꼭대기의 **마스터 시계**가 매 분 전기 펄스를 보내고, 마을의 공공 시계(시청·여관·약국·성당)는 전선으로 연결된 **자시계**라 펄스로만 움직인다.
  → 마스터 시계가 멈추면 **연결된 시계 전부가 같은 시각에 멈춘다.** (태엽식 개인 회중시계·빵집 괘종시계는 연결 안 됨 → 계속 간다)
- 사건일: 10월 28일 밤 자정. 플레이 시작은 10월 29일 아침.

| 00:05 | 금고 둘째 문은 "시계공의 종소리 가락"으로만 열린다. 오스카가 거부 → 루시앙이 오스카를 **지하 창고에 가둠**, 통로의 작업실 쪽 문을 탑 쪽에서 막음 |
| 00:40경 | 루시앙 귀가. 다음 날 "광장 시계를 보니 12시 반이라 서둘러 집에 갔다"고 거짓말 (**광장 시계는 12:00에 멈춰 있었으므로 불가능**) |
| 10/29 아침 | 이자벨이 잠긴 작업실 발견 → 탐정(플레이어) 호출 |

**범인: 루시앙 / 동기: 시계탑 지하 창건자 금고 / 방법: 시청 편지지로 협박 편지를 써서 오스카가 직접 시계를 멈추게 함**

## 8. 최종 추리와 엔딩

질문 3개: ① 범인 ② 동기 ③ 방법
- **진 엔딩 「자정의 종소리」**: 셋 다 정답. 오스카 구출, 루시앙 체포, (H1 해결 시) 창건자의 편지 낭독 추가 장면
- **보통 엔딩 「멈춘 채로」**: 범인 정답, 동기/방법 중 오답 있음. 루시앙 체포되나 금고의 의미는 묻힘
- **배드 엔딩 「사라진 시간」**: 범인 오답. 루시앙이 금고 물건을 들고 마을을 떠나고 오스카만 구출됨

모든 핵심 증거는 최종 추리 전에 반드시 얻게 되어 있다 (진행 잠금이 증거 획득에 걸려 있음).
