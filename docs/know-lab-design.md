## 2. IQ 테스트와 다른 점
- IQ = 생성기로 만든 추론 퍼즐 / 상식 = **사실 기반 문제은행** (출처·검증 날짜·검수 상태)
- 혼자 검사 점수에 **풀이 속도 안 넣음** (아는지가 중요). 빠르기는 멀티 대결 점수에만
- **찍기 보정**: 보기 수만큼 찍을 확률을 빼서 계산 → 다 찍으면 약 14점, 다 알면 100점
- 10종 미니게임마다 다른 조작 (지도 누르기, 타임라인 끌어놓기, 짝 연결, 단서 공개, 숫자 입력, 가짜 고르기)

## 5. 채점
- 문항 가중치: 쉬움 1 · 보통 1.6 · 어려움 2.4 · 전문가 3.4 (최후의 상식왕 ×1.25)
- 부분 점수: 순서(짝 맞춤 비율, 찍기=0, 완벽 아니면 최대 0.8) · 연결(같은 방식) · 숫자(허용 범위 안 만점, 근접 최대 0.7) · 정체(단서 1개 1.0 → 2개 0.85 → 3개 0.7 → 4개 0.55)
- 종합 = 가중·찍기보정 정답률 85% + 분야 균형 15% (0~100)
- 분야 점수: 문항 적으면 50점 쪽으로 당김 + 신뢰도(5개↑ 높음, 3~4 보통, 1~2 참고)
- LV.1~10 (상식 새싹 → 전설의 상식왕), 진단 유형 32종, 특별 칭호 10종
- 안내: "플레이듀오 자체 게임 지표, 공인 지능검사 아님"

## 6. 문제은행 정책
- 상태: draft(출제 안 함) → checked(자동검사 + AI 근거 대조) → approved(운영자 승인) / hold(출제 중단)
- 지금 93문항 전부 **checked(AI 근거 대조)** — 운영자 승인(approved)은 0개. 사람 검수 화면은 admin에 만들 예정
- 자동 검사: 형식, id·문제 중복, 보기 중복, 정답이 보기 안에 있는지, 연도 같은 사건 금지(순서 모호), 거짓 문장 정확히 1개, 숫자 정답=만점·먼 답=0점, 화면 정보에 정답 재료 없음, 출제 시뮬레이션
- 바뀔 수 있는 사실(인구·기록·현직자)은 넣지 않음

현재 분포 (목표 1,000): 역사 13/150 · 과학 28/150 · 지리 20/150 · 문화 11/150 · 생활 8/150 · 경제기술 11/100 · 종합 2/150
난이도: 쉬움 25% · 보통 38% · 어려움 30% · 전문가 8% (목표 30/45/20/5 — 4단계에서 맞춤)
